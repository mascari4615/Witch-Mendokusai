# Combat SFX

`generate.py` 가 같은 저장소의 두 묶음만 섞어 만든 파생 음원. 외부 파일 없음.

- `UI Soundpack` 유래 (Nathan Gibson, CC BY 4.0, 크레딧 필수): warning, swarm_warning, boss_warning, telegraph_charge, player_death, heal, victory, defeat, boss_kill 의 화음
- `RPG Sound Pack` 유래 (ArtisticDude, OpenGameArt, CC0): boss_appear, boss_kill 의 타격, telegraph_fire, player_hit, freeze, magnet_pull, zap1, zap2, splash1, splash2

가공: 재생 속도 변경 (음높이), 자르기, 역재생, 겹치기, 페이드, tremolo, 최고점 -3 dBFS 정규화. 44.1 kHz 16 bit 스테레오.
사람이 듣지 않고 이름과 파형 수치로 고름.

## 출처 표기

- Universal UI Soundpack, Nathan Gibson, CC BY 4.0, https://nathangibson.myportfolio.com, https://creativecommons.org/licenses/by/4.0/. 이 묶음에서 파생: warning, swarm_warning, boss_warning, telegraph_charge, player_death, heal, victory, defeat, boss_kill
- RPG Sound Pack, ArtisticDude, CC0, https://opengameart.org/content/rpg-sound-pack. 표기 의무 없음
- 무기 공용음 5종 (WeaponThrow, WeaponSwing, WeaponZap, WeaponSplash, WeaponHitLight) 과 MonsterPop 은 위 두 묶음에서 만든 파생물이 될 예정. 새 외부 묶음을 쓰면 이 목록에 제목, 작가, 라이선스, 주소를 먼저 추가
