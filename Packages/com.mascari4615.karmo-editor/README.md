# KarmoEditor 🐾

Unity 에디터 작업 효율을 극대화하기 위한 KarmoLab 전용 툴셋 패키지입니다.

## 🚀 주요 기능

### 1. Build Helper

- 빌드 산출물 자동 정리 및 버전 접두사 자동 할당.
- 빌드 후 특정 파일 제거 및 라이브 폴더 자동 배포 기능.

### 2. Mutex Killer (Debug Utils)

- 실행 중인 앱의 뮤텍스를 강제 종료하여 멀티 인스턴스 개발 편의성 증대.
- 리플렉션을 통한 정적 필드 초기화로 에디터 재시작 없는 가벼운 디버깅 지원.

### 3. Scene Selector Toolbar

- 유니티 상단 툴바에서 자주 사용하는 씬으로 즉시 이동.
- 폴더 내 전체 씬 자동 로드 및 필터링 기능.

### 4. Asset Selector Toolbar

- 유니티 상단 툴바에서 자주 사용하는 에셋을 빠르게 Inspector에서 확인.
- 설정 파일에 등록한 에셋 목록을 드롭다운으로 제공.
- 선택 시 해당 에셋이 자동으로 Selection되어 Inspector에 표시.

## 🛠️ 시작하기

1. 패키지 설치 시 나타나는 **Welcome Wizard**를 통해 초기 설정을 진행하세요.
2. `Edit > Project Settings > KarmoLab` 메뉴에서 모든 설정을 한눈에 관리할 수 있습니다.
3. **단축키**:
    - `Ctrl + Alt + B`: 빌드 헬퍼 열기
    - `Ctrl + Alt + M`: 뮤텍스 강제 종료
    - `Ctrl + Alt + K`: 설정 창 열기

## 🔍 전역 검색 통합

- `Ctrl + K` (유니티 검색 창)에서 `kl:` 접두사를 입력하여 패키지 기능을 검색하고 바로 실행할 수 있습니다.
