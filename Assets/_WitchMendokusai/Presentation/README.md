# WM.Presentation — 게임을 모르는 표현 부품

> 한 저장소에 여러 게임이 산다(본편 · 방치형 · 앞으로 더).
> 여기 있는 것은 **어느 게임에도 안 매인** 표현 부품이다 — 다각형, 튀는 숫자, 코드로 만든 소리, 흔들림.

## 왜 `WM.Core` 가 아닌가

`WM.Core` 는 방치형 빌드에서 **통째로 빠진다**(`WM_IDLE` 표식).
거기 두면 따로 파는 게임이 공용 부품을 못 쓴다.
그래서 **양쪽 다 참조할 수 있는** 별도 층으로 둔다.

## 규칙

- **게임 개념을 안 담는다.** 「등급」·「슬라임」 같은 말이 들어오면 그건 게임 층 것이다.
  여기서는 `sides`(변의 수)·`tone`(음) 처럼 <b>보이는 것/들리는 것</b>으로만 말한다.
- 엔진은 안다(UI Toolkit · AudioSource). 판정은 모른다.
