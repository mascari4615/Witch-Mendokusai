### 기능 확인 — 말하기

이 원고는 이야기가 아니라 **기능 확인용**이다. 대사·지문·나레이션·선택지·조건·기다림·보상이 한 번씩 나온다.

> 링: "여기서부터는 시험이야."
> 욘: (하품) "...알겠어."
> "말하는 이 없는 줄은 나레이션이 된다."

### 기능 확인 — 기다림

> wait 1s
> 링: "일 초 기다렸어."

### 기능 확인 — 선택지

> 링: "뭘 해볼까?"
> - 보상을 받아본다 -> 기능 확인 — 보상
> - 조건을 확인한다 -> 기능 확인 — 조건
> - 그냥 끝낸다 -> 기능 확인 — 끝

### 기능 확인 — 보상

> !아이템 1001
> 링: "물건 하나 줬다. 가방을 확인해봐."
> -> 기능 확인 — 끝

### 기능 확인 — 조건

> ?아이템 1001 -> 기능 확인 — 가졌다
> 링: "그 물건은 아직 없네."
> -> 기능 확인 — 끝

### 기능 확인 — 가졌다

> 링: "그 물건을 가지고 있구나."

### 기능 확인 — 끝

> 욘: "이걸로 끝."
